# RedShot

Скриншоты для Windows 10 x64. Живёт в трее, без окна в панели задач.

Режимы: область, активное окно, монитор под курсором. После снимка — оверлей с разметкой. Enter / Ctrl+C копирует PNG в буфер и сразу пишет файл. Esc — отмена.

## Горячие клавиши

Меняются в трее → Настройки.

| | по умолчанию |
| --- | --- |
| Область | Print Screen |
| Активное окно | Alt+Print Screen |
| Весь экран (монитор курсора) | Ctrl+Print Screen |

Если Print Screen открывает ножницы Windows: Параметры → Специальные возможности → Клавиатура → «Использовать кнопку Print Screen для запуска ножниц» — выкл.

В оверлее:

| | |
| --- | --- |
| Копировать, сохранить, закрыть | Enter или Ctrl+C |
| Сохранить как… | Ctrl+S |
| Отмена / повтор | Ctrl+Z / Ctrl+Y |
| Выход без копии | Esc |
| Точное выделение | стрелки (до клика / при перетаскивании рамки) |
| Инструмент, цвет, толщина | зажать ПКМ → сектор → отпустить |
| Рисовать | ЛКМ |
| Сбросить штрих | короткий ПКМ |

Инструменты: карандаш, маркер, стрелка, линия, прямоугольник, эллипс, текст, размытие, ластик.

## Файлы

Копия кладёт PNG в `%USERPROFILE%\Pictures\RedShot\<YYYY-MM>\redshot-<unix>.png`. Папку можно сменить в настройках; подпапки по месяцам остаются. Ctrl+S — диалог, стартовый путь тот же.

Настройки: `%APPDATA%\redshot\settings.json`. Лог: трей → «Открыть лог» (`%APPDATA%\redshot\redshot.log`). Автозагрузка — чекбокс в настройках.

## Запуск и сборка

Node.js 20+, Windows 10 x64.

```
npm install
npm run dev
```

Портативный exe (без установки, без админа): `npm run pack` → `release/RedShot-1.0.0-portable.exe`.
