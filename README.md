# RedShot

Утилита скриншотов для Windows 10: область, разметка через кольцевое меню, копирование в буфер.

## Запуск

Нужны Node.js 20+ и Windows 10 x64.

```
npm install
npm run dev
```

Приложение живёт в трее. Если `Print Screen` открывает ножницы Windows: Параметры → Специальные возможности → Клавиатура → «Использовать кнопку Print Screen для запуска ножниц» — выключить.

Лог ошибок: трей → «Открыть лог», файл `%APPDATA%\\redshot\\redshot.log`.

## Сборка exe

```
npm run pack
```

Файл: `release/RedShot-1.0.0-portable.exe` (без установки, без прав администратора).

## Горячие клавиши

По умолчанию (меняются в трее → Настройки):

| Действие | Клавиши |
| --- | --- |
| Снимок области | Print Screen |
| Активное окно | Alt+Print Screen |
| Весь экран | Ctrl+Print Screen |

В оверлее:

| Действие | Клавиши |
| --- | --- |
| Копировать и закрыть | Ctrl+C или Enter |
| Сохранить PNG | Ctrl+S |
| Отмена / повтор | Ctrl+Z / Ctrl+Y |
| Выйти без сохранения | Esc |
| Инструмент | зажать ПКМ, сектор, отпустить |
| Рисовать | ЛКМ |
| Сбросить штрих | короткий ПКМ |
